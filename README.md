# Future Skills Initiative

Empowering students with practical digital skills for the future.

## About

The Future Skills Initiative is a social impact project aimed at supporting high school and early university students by providing accessible, hands-on technology education. Many students lack guidance in learning modern digital skills — this initiative exists to help bridge that gap.

This project is currently being developed as part of the **Millennium Fellowship 2026**.

## What We Do

- Teach basic artificial intelligence concepts
- Share practical digital skills
- Organize online and in-person learning sessions
- Create simple educational content for wider reach

## Impact Goals

- Reach 80+ students in the first cohort
- Build a supportive learning community
- Improve access to quality technology education

## Tech Stack

This is a static landing page built with:

- **HTML5** — semantic markup
- **CSS3** — custom properties, Flexbox, Grid, responsive media queries
- **JavaScript** — mobile navigation, scroll animations (IntersectionObserver)
- **Google Fonts** — Inter (body) and Poppins (headings)
- **Unsplash** — royalty-free imagery

No frameworks, no build tools, no dependencies.

## Project Structure

```
future-skills-initiative/
├── index.html   # Page markup and structure
├── style.css    # All styles, layout, and responsive rules
├── main.js      # Navigation toggle and scroll animations
└── README.md
```

## Getting Started

Open `index.html` in any browser — no installation or build step required.

To run with a local server (optional):

```bash
# Using Python
python -m http.server 5500

# Using Node (npx)
npx serve .
```
